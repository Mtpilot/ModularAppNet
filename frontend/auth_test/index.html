🔗 Перейти в Swagger с авторизацией

Как использовать:

  1. Нажмите на ссылку "Перейти в Swagger"
  2. В открывшемся Swagger UI нажмите кнопку "Authorize"
  3. Вставьте токен в формате: Bearer ваш_токен
  4. Нажмите "Authorize" и "Close"
